# Job Description — Mid-Level Backend Engineer

We're looking for a backend engineer with 3–5 years of experience to join our platform team.

## Responsibilities

- Design and maintain REST APIs serving production traffic
- Own data models and write efficient SQL queries
- Work with cloud infrastructure (AWS or GCP) for deployment and scaling
- Collaborate with frontend and product teams
- Participate in code review and mentor junior engineers

## Requirements

- 3–5 years professional backend development experience
- Strong proficiency in Python or Go
- Experience designing and consuming REST APIs
- Solid SQL and relational data modeling skills
- Hands-on experience with cloud infrastructure (AWS/GCP/Azure)
- Comfortable working in a team, giving/receiving code review feedback

## Bonus

- Experience with containerization (Docker/Kubernetes) or CI/CD pipelines
- Experience leading small technical initiatives

## Evaluation Skill Categories (for scoring)

1. Python/Go proficiency
2. REST API design
3. SQL / data modeling
4. Cloud infrastructure experience
5. Ownership & collaboration (soft signal)
